# 1. 직접 생산 작업표준

## 1. 개요
- 생산팀장과 작업자는 본 매뉴얼에 따라 공정을 실행하며, 품질관리는 이를 검증·기록하여 공정이 규정된 관리 상태를 유지한다.

## 2. 적용 범위
- 보행매트, 식생매트 등 자사 생산 제품의 전체 제조 공정에 적용한다.
- 원부자재 입고부터 완제품 출하까지의 모든 단계를 포함한다.

## 3. 목적
- 일관된 품질 확보: 공정 조건과 관리 항목을 명확히 하여 고객 요구사항을 충족한다.
- 작업 효율성 향상: 작업 표준을 통일하여 생산자의 숙련도와 무관하게 일정한 결과를 낸다.
- 문제 예방 및 대응: 검사와 기록을 통해 이상을 조기에 발견하고, 재발 방지를 위한 자료를 축적한다.

## 4-1. 보행매트

생산 프로세스: 원자재 입고 → 이송 → 직조 → 중간검사 → 재단 → 제품검사 → 포장 → 보관 → 출고

1. 원자재 입고 — 원자재 입고 시 인수검사 진행. 책임자: 품질관리자 / 생산팀장
2. 원자재 이송 — 이송 전 로프 상태 확인(오염, 풀림 등 결함 없을 것). 로프 중심부가 풀려서 엉키거나 심봉이 부서져 거치 불가한 경우 작업용 용기에 풀어서 위사로 사용. 직조기 경사 보빈에 코이어 로프 장착, 직조기 위사 공급기에 코이어 로프 장착. 책임자: 생산팀장 / 작업자
3. 직조 — 설비 운전자는 설비운전표준, 직조기 매뉴얼을 반드시 숙지. 직조 상태 확인: 직조이상, 경사누락(상태 이상 매트는 불량처리). 설비 운전 상태 확인: 경사 텐션 이상(보빈 풀림 과정에서 로프 끼임, 풀러·가이드·업다운 스틱에 로프 연결부 끼임, 풀러와 룸박스롤러의 공급 비율 확인), 위사 공급 이상, 에어 및 동력 공급·센서 이상. 책임자: 생산팀장 / 작업자
4. 중간검사(공정 품질 검사) — 규격 및 로트 변경 시 초물(세팅) 검사. 책임자: 생산팀장 / 품질관리자
5. 재단 — 와인딩 → 재단 → 마감. 마감 상태 확인: 빠짐없이 결속되어 위사 이탈되지 않음. 책임자: 작업자
6. 제품검사(공정 품질 검사) — 랜덤 팝업 검사. 자동화 보고서에 팝업이 뜨면 기록함. 책임자: 생산팀장 / 품질관리자
7. 포장 — 와인딩 상태 확인, 밴딩, 식별표 부착. 책임자: 작업자 / 생산팀장 확인
8. 보관 — 적재 시 기울어짐 없게, 직사광선·습기 피함. 책임자: 생산팀장
9. 출고 — 상하차/운송 시 충격·습기 방지(갑바포장 필수). 고객이 요구하는 방식·기한을 지켜 납품. 책임자: 경영간부

## 4-2. 식생매트

생산 프로세스: 입고 → 이송 → 투입(적층) → 재봉 → 중간검사 → 재단 → 제품검사 → 포장 → 보관 및 출고

1. 원자재 입고 — 입고 시 인수검사 진행. 코이어네트 와인딩: 2×20m 네트 5개 번들을 풀어 로드(봉)에 와인딩, 와인딩 과정에서 길이 확인. 책임자: 품질관리자 / 생산팀장
2. 원자재 이송 — 이송 전 원자재 확인(찢김, 오염, 풀림 등 결함 없을 것). 적층 원단 거치대 거치, 봉재용 실 거치(8본). 책임자: 생산팀장 / 작업자
3. 투입(적층) — 제품 규격별 적층 순서(하층→상층). DB-G01 인장력 강화형: 씨줄네트 → 코이어블랑켓 → 왕코이어네트 → PE강성망. DB-G02 고강도형: 씨줄네트 → 코이어블랑켓 → 코이어네트 → 황마네트. DB-G03 일반형: 황마씨네트 → 코이어네트 → 황마네트. DB-G04 저강도형: PE차광망 → 황마씨네트. 사전 장비 점검: 길딩기, 재단기. 책임자: 생산팀장 / 작업자
4. 재봉 — 적층된 자재를 재봉. 설비 운전자는 설비운전표준, 길딩기 매뉴얼 반드시 숙지. 봉재 상태 확인: 뭉침, 찢김, 이격 등 결함. 설비 운전 상태 확인: 끼임·걸림(노루발, 거치대, 와인더), 동력 장치(모터), 바늘(봉재 상태, 땀수). 책임자: 생산팀장 / 작업자
5. 중간검사(공정 품질 검사) — 규격 및 로트 변경 시 세팅검사. 책임자: 생산팀장 / 품질관리자
6. 재단 — 재단기 사용 시 안전주의. 끼임으로 장비 정지 시 반드시 전원 끄고 제거할 것. 책임자: 생산팀장
7. 제품검사(공정 품질 검사) — 랜덤 팝업 검사. 자동화 보고서에 팝업이 뜨면 기록함. 책임자: 생산팀장 / 품질관리자
8. 포장 — 비닐 포장(방습 확인), 밴딩, 식별표 부착. 책임자: 작업자 / 생산팀장 확인
9. 보관 및 출고 — 하부 파레트 깔고 적재. 직사광선·습기 주의. 출하 전 포장 및 식별표 재확인. 책임자: 품질관리자 / 경영간부
