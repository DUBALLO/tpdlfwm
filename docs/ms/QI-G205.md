# DB-QI-G205 씨줄네트 인수검사 및 지침

## 1 적용범위

이 규격은 당사에서 생산하는 식생매트 부직포(PLA) 재료의 인수검사 규격에 대하여 규정한다.

## 2 종 류

2. 씨줄네트 (seed rope net)

종이펄프에 종자 또는 영양분을 넣어 말아 감싸고 새끼줄처럼 꼬아서 만든 펄프로 된 줄을 황마네트 박음질하여 부착한 것

## 3 품 질

### 3.1 겉모양

파손 ,이물질 등의 사용상 해로운 결함이 없어야 한다.

3.2 인장강도와 인장신도 및 질량은 아래 기준에 적합하여야 하며, 인장강도와 인장신도 검사는 연 2회 (전반기, 하반기) 실시하되 외부 공인기관 성적서로 대체할 수 있다.

| 구분 | 품질기준 | 비고 |
|---|---|---|
| 질량(g/㎡) | 300 이상 |  |
| 두께(㎜) | 2.0 |  |
| 인장강도(kN/m) | 1.0 이상 | 공인기관성적의뢰 |
| 인장신도(%) | 25 % 이상 |  |

## 4 검사로트의 구성 및 검사단위체

종류별 1일 입하량을 1검사 로트로 하고 제품 1㎡를 1검사 단위체로 한다.

5. 검사항목, 검사방식, 검사조건 및 판정기준은 표 1에 따른다.

표 1

비 고 1. KS표시 허가품은 검사를 생략할 수 있다.

| 순서 | 검사항목 | 검사방식 및 조건 | 판정기준 |
|---|---|---|---|
| 1 | 겉모양 | 체크검사 n = 1, c = 0 | 3.1항에 적합할 것 |
| 2 | 질량 | 체크검사 n = 1, c = 0 | 3.2항에 적합할 것 |

2. 1항,2항 자체검사를 실시하고 이상 유무를 기록 관리 한다.

## 6 시료 채취 방법

KS Q 1003(랜덤샘플링 방법)에 따른다.

## 7 시험 및 검사방법

### 7.1 겉모양

3.1항의 품질요건을 만족하는지 육안으로 조사한다.

7.2 인장강도 인장신도는 외부공인기관에 시험성적 의뢰하며, 질량은 3.2항 기준에 적합하여야 한다.

## 8 검사로트의 처리

8.1 불합격된 로트는 반품 처리함을 원칙으로 하고, 기타 사항은 부적합제품관리(DB-QP-F301)에 따라 처리한다.

8.2 검사 및 시험업무 절차서(DB-QP-F103)에 따라 검사결과는 기록되고 보관되어야 한다.
