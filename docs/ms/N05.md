# 5. 자주 검사 매뉴얼

- 자주검사는 생산자가 공정 진행 중 스스로 실시하는 검사로, 불량을 조기에 발견하고 조치하여 안정된 품질을 유지하는 데 목적이 있다.
- 책임자: 생산팀장 / 품질관리자

## 보행매트

### 1. 인수검사
- 거래명세표 대조: 납품된 롤 수량이 발주 및 거래명세서와 일치하는지 확인
- n=1, c=0 기준검사(샘플 1개, 불합격 0개)
- 외관: 올 풀림, 이물질, 곰팡이, 파손 여부 확인 → 육안검사
- 두께: 17-18T(±10%) / 18-20T(±10%) → 버니어 캘리퍼스
- 꼬임수: 8가닥 확인 → 풀어서 단사 확인
- 선밀도(단위중량): 45g/m 기준 → 1m 잘라서 중량 확인

### 2. 중간검사(공정 품질 검사)
- 규격 및 로트 변경 시 초물/세팅검사. 목적: 로프 두께 편차에 맞게 직조 밀도를 조정하여 적정 두께 설정
- n=1, c=0 기준 검사. 폭 → 매트 폭 측정(합격 기준 +5~10%). 두께 → 하이트 게이지 + 지그로 측정(합격 기준 +5~10%)
- 판정: 합격 조건 충족 시 해당 조건으로 연속 생산 진행

### 3. 제품검사(공정 품질 검사)
- 순회/랜덤 검사. 자동화 보고서에 팝업이 뜨면 기록함
- n=1, c=0 기준 검사. 폭 → 매트 폭 측정(+5~10%). 길이 → 매트를 바닥에 깔고 줄자로 측정(+5~10%). 두께 → 하이트 게이지 + 지그
- 판정: 불합격 시 생산 중단 → 조건 재조정 후 재검사

## 식생매트

### 1. 인수검사
- 거래명세표 대조: 품목, 수량, 주요 규격 확인
- 네트류(황마네트, 코이어네트, PE강성망, PE필름네트): 외관(손상, 올 풀림, 이물질, 곰팡이, 찢김 없음 → 육안), 치수(폭·길이 규격 → 줄자), 중량(㎡당 질량 → 저울)
- 섬유/블랑켓류(코이어블랑켓, 부직포): 외관(이물 혼입, 곰팡이, 손상 없음 → 육안), 두께(규격치 이상 → 버니어 캘리퍼스), 중량(㎡당 질량 → 저울)
- 종자층 자재(식생지, 씨줄네트): 외관(종자 고정 상태 양호, 풀림·절단 없음, 곰팡이·변질·발아 없음 → 육안), 치수(줄자), 중량(저울)

### 2. 중간검사(공정 품질 검사)
- 규격 및 로트 변경 시 세팅검사. n=1, c=0(샘플 1개 불합격 시 로트 전체 불합격)
- 외관 → 육안: 이물, 풀림, 찢김, 재봉상태 이상 없음. 적층구조 확인
- 치수 → 측정: 폭, 두께, 길이, 중량, 땀 간격(폭 200mm). 줄자, 버니어 캘리퍼스, 전자저울. 합격 기준 +5~10%

### 3. 제품검사(공정 품질 검사)
- 랜덤 팝업 검사. 자동화 보고서에 팝업이 뜨면 기록함
- 외관 → 육안: 이물, 풀림, 찢김, 재봉상태 이상 없음. 적층구조 확인
- 치수 → 측정: 폭, 두께, 길이, 중량, 땀 간격(폭 200mm). 합격 기준 +5~10%
