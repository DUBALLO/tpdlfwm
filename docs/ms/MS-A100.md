## 위키에서 자리 옮기는 것
- (08) 재무 관리 안의 인사·교육·구인·급여 → 2장 구성원. (08)은 재무·총무만 남음.
- (04) 업무 매뉴얼 안의 사업자정보·증빙인증서류 → 1장 회사. 조달 계열 → 5장 영업.
- (01) 제품/생산기술 안의 원자재·재고·송장출고 → 6장, 검사 및 시험 → 7장. (01)은 제품 규격만 남음.
- (03) 구성원 안의 인프라·도구 → 3장. (10) 작업장 환경개선 → 3장.
- (07) 디자인연구소 → 4장 설계개발의 기록.

## 삭제·통합 (절차서 35 → 27 + 신설 3)
- 삭제: D101 자금관리(빈 문서), F401 품질분임조.
- 통합: B201→B101, C501→C401, D402→D401, E502→F103, F402→F303.
- 신설: 인사·복무 규정(2장), 시공 절차(6장, 현재 절차서 없음 — 직접시공이 매출 축인데 규정 공백), 재무·총무 규정(8장).

## 매뉴얼 본문 = 이 표
장마다 한 쪽: 목적 한 문단 · 책임(대표/생산팀장/작업자/AI) · 절차서 목록 · 지침 위치 · 기록과 수집처. ISO 대응표와 KS 인용표는 부표. 용어는 KS Q ISO 9000 인용 + 사내 용어 10개.
