# 6. 시공 매뉴얼

## 첨부(노션)
- 시공 준비물 체크리스트 - 보행매트 (hwp)
- 시공 준비물 체크리스트 - 식생매트 (hwp)
- 보행매트 시공가이드, 식생매트 시공가이드 (노션 하위 페이지)
- 보행매트 시공 자재 (hwp), 작업현황판 A3·A4 (hwp)

## 보행매트 외주설치
- 현장도착도
- 평탄구간 헤베 당 3-4000원 / 일반적으로 5-6000원
- 소운반 / 아루(꺾임) / 성토면 다지기 추가비용 발생
- 일식 100만원 계산
- 수량 많은 때는 실측 / 수량 적을 때는 현장사진으로 견적발행 가능
- 별도 계약 또는 관급자재로 환산

## 식생매트 외주설치
- 현장도착도 / 제품 보증 차원에서 설치를 획득하는 것이 좋다.
- 계약금액 5000만원 이상은 면허가 필요하다
- 일반적으로 책정되는 공사금액 헤베 당 4-5000원
- 청산은 1500-2000원 선
