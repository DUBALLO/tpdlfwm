# DB-QI-I102 식생매트 중간검사지침

## 1 적용범위

이 표준은 당사에서 생산하는 식생 매트의 제품의 제조공정에 대한 품질 및 공정검사

(이하“중간검사”라 한다)에 대하여 규정한다.

## 2 종 류

식생매트 종류 표1에 따른다 표 1

| 종류 | 식생매트 명칭 | 구성요소 | 용도 |
|---|---|---|---|
| 1종 | 인장력강화형 | 보강층 + 표면층 + 보온·보습층 +<br>종자층 | 저수호안 |
| 2종 | 고강도형 | 표면층 + 보온·보습층 + 종자층 |  |
| 3종 | 일반형 | 보온·보습층 + 종자층 | 고수호안 |
| 4종 | 저강도형 | 종자층 |  |
| 5종 | 특수형 | 특수층을 포함한 구성 | 저수호안/고수호안 |

## 3 품 질

품질은 다음의 공정별 품질요건에 적합하여야 한다.

3.1 구성층별로 결함이 없는 상태에서 재봉이 되어 있어야 한다.

3.2 재봉시 각층의 마감부에 이격이 없어야 한다.

### 3.3 치수 및 허용차

식생매트의 치수는 표 2와 같다. 폭의 허용차는 표시치의 ±5 % 이내이어야 하며, 두께는 표시치 이상이어야 한다.

표 2 - 치수 및 허용차

| 종류 | 폭(㎜) | 두께((㎜) | 길이(m) |
|---|---|---|---|
| 1종(인장력강화형) | 2000 | 10 | 20 |
| 2종(고강도형) | 8 |  |  |
| 3종(일반형) | 6 |  |  |
| 4종(저강도형) | 2 |  |  |
| 5종(특수형) | 6 |  |  |
| 비고 현장 상황 및 설계에 따라 폭과 길이를 협의할 수 있다. |  |  |  |

## 4 시험방법

### 4.1 겉모양

3.1항의 품질요건을 만족하는지 육안 및 감각으로 조사한다.

### 4.2 치수, 두께

버니어 캘리퍼스로 측정한다.

### 4.3 중량

전자저울로 측정한다.

4.4. 길이는 30M 줄자로 측정한다.

4.5 구성 비율은 식생매트 종류에 따라서 육안으로 확인한다.

## 5 검사방법

### 5.1 검사로트의 형성

종류별, 일일 생산량을 1 검사로트로 한다.

### 5.2 검사단위체

정해진 단위로 생산된 식생매트 1롤을 검사단위로 한다.

(단, 인장강도, 인장신도는 6개월 생산량을 검사로트로 한다.)

### 5.3 검사항목, 검사방식, 검사조건 및 판정기준

검사항목, 검사방식, 검사조건 및 판정기준은 표 3에 따른다.

표 3 - 검사항목

| 순번 | 검사항목 | 검사방법 | 검사조건 | 비 고 |
|---|---|---|---|---|
| 1 | 겉모양 | 체크검사, 육안 | n=1, c=0 |  |
| 2 | 구성비율 |  |  |  |
| 3 | 박음질상태(땀수) |  |  |  |

### 5.4 시료 채취 방법

생산된 제품으로부터 임의로 시료를 지정한다.

6. 검사로트의 처리

6.1 불합격된 로트는 반품 처리함을 원칙으로 하고, 기타 사항은 부적합제품관리(DB-QP-F301)에 따라 처리한다.

6.2 검사 및 시험업무 절차서(DB-QP-F103)에 따라 검사결과는 기록되고 보관되어야 한다.
