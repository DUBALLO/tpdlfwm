# DB-QI-I101 보행매트 중간검사지침

## 1 적용범위

이 표준은 당사에서 생산하는 보행용 코이어매트의 제품의 제조공정에 대한 품질 및 공정검사(이하“중간검사”라 한다)에 대하여 규정한다.

## 2 종 류

보행매트의 종류는 표 1과 같이 구분한다.

표 1 – 보행 매트의 종류

(단위:mm)

| 종류 | 두께 | 폭 | 비고 |
|---|---|---|---|
| 20T | 20 | 600, 800, 1000, 1200, 1500, 1800, 2000, 2500, 3500, 4000, 4500, 5000 | 등산로용, 둘레길용 등 |
| 30T | 30 |  |  |
| 35T | 35 |  |  |

## 3 겉모양

3.1 전체가 반듯하여야 하며 안정성이 있어야 한다.

3.2 색상은 이색 없이 균일하여야 한다. 다만, 무늬를 요구하는 것은 제외한다.

3.3 고정핀을 삽입하기 쉬워야 하며, 설치가 용이하도록 하되, 설치 후 헐거움이나 흔들림이 없이 견고하여야 한다.

3.4 모서리 등은 날카로움이 없어야 하며, 다듬질이 양호하여야 한다.

4. 재료 보행용 코이어매트에 사용하는 원료는 보행매트의 품질을 만족할 수 있는 표 2에 적합한 코이어 로프를 사용하여야 한다.

표 2 – 코이어 로프의 품질

| 시험 항목 | 품질 |  |  | 시험방법 |
|---|---|---|---|---|
| 20T | 30T | 35T |  |  |
| 심사의 재질 | 천연섬유 |  |  | KS K 0210-1 5.4와 5.8 |
| 로프굵기(mm) | 14 ± 2.8 | 17 ± 3.4 | 20 ± 4.0 | 9.3 |
| 선밀도(g/m) | 40 이상 | 50 이상 | 60 이상 | 9.4 |
| 인장강도(kN) | 0.8 이상 | 1.0 이상 | 1.2 이상 | 9.5 |

5. 치수 및 허용차 보행용 코이어매트의 치수 및 허용차는 표 3 과 같다. 다만, 표 3 이외의 치수를 수요처와 협의에 따라 변경할 수 있다.

6. 시험방법

6.1 겉모양 3.1항의 품질요건을 만족하는지 육안 및 감각으로 조사한다.

6.2 로프의 굵기 버니어 캘리퍼스로 측정한다.

6.3 중량 전자저울로 측정한다.

6.4. 길이는 30M 줄자로 측정한다.

6.5 구성 비율은 보행용 코이어매트 종류에 따라서 육안으로 확인한다.

7. 검사방법

7.1 검사로트의 형성 종류별, 일일 생산량을 1 검사로트로 한다.

7.2 검사단위체 정해진 단위로 생산된 보행매트 1롤을 검사단위로 한다.

(단, 인장강도, 인장신도는 6개월 생산량을 검사로트로 한다.)

7.3 검사항목, 검사방식, 검사조건 및 판정기준 검사항목, 검사방식, 검사조건 및 판정기준은 표 4에 따른다.

7.4 시료 채취 방법 생산된 제품으로부터 임의로 시료를 지정한다.

8. 검사로트의 처리

8.1 불합격된 로트는 반품 처리함을 원칙으로 하고, 기타 사항은 부적합제품관리(DB-QP-F301)에 따라 처리한다.

8.2 검사 및 시험업무 절차서(DB-QP-F103)에 따라 검사결과는 기록되고 보관되어야 한다.
