# DB-QP-E103 고객을 위한 구매정보

## 1 목적

고객이 사기 전에 제품을 비교하고 고를 수 있도록 정확하고 최신인 정보를 준다. 어느 경로로 보든 같은 제품에 같은 정보가 나가게 한다.

## 2 적용 범위

두발로 제품과 직접시공에 대해 계약 전후로 고객에게 주는 모든 정보에 적용한다. 홈페이지, 조달 등록 정보, 카탈로그, 견적서, 납품 서류를 포함한다.

## 3 용어

| 용어 | 뜻 |
|---|---|
| 구매정보 | 고객이 사기 전에 고르는 데 쓰는 정보. 규격, 성능, 가격, 시공 방법 등 |
| 홈페이지 | duballo.kr(노션·우피). 단가표, 다운로드(설계자료·카탈로그), 시공사례를 싣는다 |
| 조달 등록 정보 | 나라장터 종합쇼핑몰과 S2B에 등록한 규격서·단가·이미지 |
| 규격서 | 조달에 등록한 제품 규격 문서. 원본은 조달 업로드본이다 |

## 4 책임

| 역할 | 책임 |
|---|---|
| 실장 | 공개할 정보 결정·승인, 조달 등록 정보 관리, 고객 요청 자료 제공 |
| 생산팀장 | 규격·시공 방법이 바뀌면 실장에게 알림, 시공사례 사진 제공 |
| AI | 홈페이지·카탈로그·조달 등록 정보·규격서 사이 불일치 점검, 자료 초안 작성 |

## 5 업무

### 5.1 정보를 주는 곳

| 시점 | 무엇을 | 어디로 |
|---|---|---|
| 계약 전 | 회사소개, 카탈로그, 설계자료, 단가표, 시공사례 | 홈페이지, 메일 |
| 계약 전 | 규격서, 조달 단가 | 나라장터 종합쇼핑몰, S2B |
| 계약 전 | 견적서 | 메일(PWA 주문관리에 기록) |
| 계약 후 | 규격서, 시방서, 시공계획서, 시험성적서, 인증서류 | 고객이 요청하거나 납품 때 필요한 것을 메일 또는 납품 시 동봉 |

### 5.2 반드시 담을 것

- 제품 이름과 코드, 규격(폭·길이·두께·무게)
- 원료와 성능(시험성적서 근거)
- 가격과 추가 비용(운반·시공)
- 시공 방법 또는 시공 여부
- 품질보증(계약 조건을 따른다)
- 불만 접수 창구(실장 연락처)
- 제조자 이름·주소, 제조국

### 5.3 지킬 것

- 규격서·시험성적서와 다른 숫자를 쓰지 않는다.
- 광고 문구와 사실 정보를 섞지 않는다. 과장하거나 오해를 살 표현을 쓰지 않는다.
- 전문 용어는 풀어 쓴다(예: 법면 = 경사면).
- 단가표는 구글시트 단가를 원본으로 하고 홈페이지에 반영한다.

### 5.4 바뀔 때

- 규격·단가·시공 방법이 바뀌면 실장이 홈페이지, 카탈로그, 조달 등록 정보를 함께 고친다. 조달 등록 정보는 조달청 절차에 따른다.
- AI가 바뀐 내용이 모든 경로에 반영됐는지 확인하고 빠진 곳을 알린다.
- 이미 준 정보가 틀린 것을 알면 받은 고객에게 고친 정보를 다시 보낸다.

### 5.5 품질 미달이 고객에게 주는 영향

고객에게 설명할 때 쓴다.

| 항목 | 보행매트 | 식생매트 |
|---|---|---|
| 겉모양 | 제품 신뢰도 저하 | 제품 신뢰도 저하 |
| 치수·질량 | 내구성·기능 저하 | 내구성·기능 저하 |
| 인장강도 | 보행로·등산로 외부 충격에 파손, 수명 단축 | 하천·경사면 외부 충격에 파손, 수명 단축 |
| 인장신도 | 지면에서 매트가 뜰 수 있음 | 노면·지면에서 매트가 뜰 수 있음 |
| 두께 | 인장강도에 영향 | 인장강도에 영향 |

## 6 기록

| 기록 | 어디에 | 언제 | 보존 |
|---|---|---|---|
| 홈페이지 공개 정보(단가표·다운로드·시공사례) | 홈페이지 duballo.kr(노션 페이지 이력) | 변경 시 | 현행 유지 |
| 조달 등록 정보 | 나라장터 종합쇼핑몰·S2B | 변경 시 | 현행 유지 |
| 견적서 | PWA 주문관리 | 발행 시 | 5년 |
| 계약 후 제공 자료 | 해당 주문 건 또는 발송 메일 | 제공 시 | 5년 |

배포관리대장은 따로 만들지 않는다. 종이 양식은 쓰지 않는다.
