# DB-QP-B301 품질기록관리

## 1 목적

일을 한 증거를 정해진 자리에 남겨서, 문제가 생기면 바로 찾아보고 원인을 따질 수 있게 한다. 기록은 경영검토와 개선의 근거가 된다.

## 2 적용 범위

각 절차서의 "기록" 표에 적힌 모든 기록에 적용한다. 규정 문서 자체의 관리는 사내표준관리(DB-QP-B101)에 따른다.

## 3 용어

| 용어 | 뜻 |
|---|---|
| 기록 | 한 일과 그 결과를 보여 주는 증거. 폼 응답, 노션 보고서, 시트, 사진, PDF |
| 기록 목록표 | 어떤 기록을 어디에 남기는지 모은 목록. PWA 경영시스템 각 장의 기록 표 |
| 보존기간 | 기록을 지우지 않고 두는 기간. 기록이 생긴 다음 해부터 센다 |

## 4 책임

| 역할 | 책임 |
|---|---|
| 실장 | 외부 열람 승인, 보존기간 결정, 폐기 승인 |
| 생산팀장 | 생산·검사·설비 기록을 그날 입력, 빠진 기록 확인 |
| 작업자 | 일일 점검과 생산 일지를 그날 입력 |
| AI | 보고서 분류(종류·절차서 번호) 붙이기, 기록 목록표 갱신, 빠진 기록 알림, 연간 집계 |

## 5 업무

### 5.1 기록하는 곳

기록은 다음 네 곳에만 남긴다. 어느 기록이 어디로 가는지는 각 절차서의 기록 표와 기록 목록표를 따른다.

| 곳 | 무엇을 |
|---|---|
| 구글폼 → 응답 시트(공유 드라이브) | 반복 기록: 일일·주간·월간 점검, 생산·작업 일지, 인수검사, 공정 품질 검사, 지급대장 |
| 노션 생산부 보고서 DB | 사건 기록: 생산, 출고, 시공, 개선, 이상 조치, 도입, 점검, 검사, HR, 고객불만, 내부심사, 경영검토 |
| 노션 생산설비 관리대장 | 설비·검사장비 등록과 이력(보고서 연결) |
| PWA 경영시스템 | 문서대장, 기록 목록표, 주문·납품실적 |

종이 양식은 쓰지 않는다.

### 5.2 작성

- 일한 그날 입력한다. 사진이 있으면 함께 올린다.
- 노션 보고서는 보고서 종류를 고르고, 관련 설비가 있으면 연결한다.
- 절차서 번호는 사람이 채우지 않는다. AI가 정해진 목록에서 붙인다.

### 5.3 수정

- 잘못 입력한 값은 고치고, 고친 이유를 특이사항이나 댓글에 적는다.
- 노션과 구글 시트는 수정 이력이 저절로 남는다. 이력을 지우지 않는다.

### 5.4 찾기와 열람

- 회사 사람은 노션·공유 드라이브·PWA에서 바로 찾는다. PWA 경영시스템 각 장의 기록 표에서 수집처로 간다.
- 고객이나 심사원이 기록을 보자고 하면 실장이 승인하고, 필요한 부분만 사본(PDF·캡처)으로 보여 준다.
- 기록 링크를 회사 밖에 공개로 열어 두지 않는다.

### 5.5 보존과 폐기

- 보존기간은 각 절차서의 기록 표에 적는다. 법으로 정한 기간이 더 길면 법을 따른다.
- 보존기간은 기록이 생긴 다음 해부터 센다.
- 보존기간이 지난 기록을 지울 때는 실장 승인을 받는다. 계속 참고할 기록은 실장이 기간을 늘린다.

### 5.6 옛 기록

2025년 9월까지의 기록 원장 QM_품질관리대장(구글 시트)은 보관용이다. 새 기록을 넣지 않고 찾아보기만 한다.

### 5.7 점검

AI가 기록 목록표의 수집처마다 마지막 기록일을 확인한다. 정한 주기보다 오래 비어 있으면 생산팀장과 실장에게 알린다. 연간 결과는 경영검토(DB-QP-C301) 자료로 쓴다.
